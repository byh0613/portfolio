# 邴元昊 · 作品集

品牌策划 / GTM 作品集，单页横滑站点（11 屏：封面 + 目录 + 9 个内容屏）。

线上地址：**https://byh0613.github.io/portfolio/**

## 结构

| 路径 | 内容 |
|---|---|
| `index.html` | 全部 11 屏的结构与文案 |
| `assets/css/site.css` | 样式：水面、卷轴纸、字体栈、翻页与入场动效 |
| `assets/js/site.js` | 交互：横滑翻页、工牌翻面、抽屉、自适应缩放 |
| `assets/fonts/` | 自托管字体（思源宋体子集 / Fusion Pixel / Silkscreen），离线可用 |
| `assets/img/` | 项目配图、瓶身像素图、工牌照 |
| `assets/cv.pdf` | 简历 PDF |

## 本地查看

直接双击 `index.html` 即可，无需构建、无外部依赖，断网也能完整打开。

字体是按站点用字子集化的，改文案后若出现字形不一致，说明新字不在子集里，需要重新生成字体子集。
